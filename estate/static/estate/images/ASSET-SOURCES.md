# Asset sources

`logo.png` is the supplied Plotmatrix logo, extracted from image object 14 (with its original transparency mask) in `Plotmatrix.pdf`. Only empty transparent margins were removed. `logo-mark.png` is a crop of the same logo, not a replacement logo.

`hero.webp`, `community.webp`, `development.webp` and `architecture.webp` are optimized versions of original raster image objects 18, 13, 19 and 20 in the supplied brochure. They are illustrative brochure imagery. They are not verified photographs of the Govindpuram site. Keep their descriptive gallery captions when publishing.

The original user-supplied brochure remains a source reference outside public assets. It is not republished because it contains unrelated template text, an unverified founding year and an anonymous endorsement. Only the original logo, illustrative imagery, factual contacts and carefully reviewed company content are used.

`govindpuram-plan.png` is a manually reconstructed illustration based on the society-plan image supplied in the conversation. It uses the same reference coordinate system (1172 × 813) as `demo-geometry.json`, with individually traced numbered plot boundaries. This illustration is not the original uploaded plan, a survey, an approved map or an offer for sale. Replace it with an administrator-verified original plan in a new layout revision before adding genuine inventory. The image itself is labelled as a demonstration reconstruction.

`demo-geometry.json` provides demonstration plot geometry and sample dimensions for the opt-in `seed_demo` command. Availability is generated only for the explicitly labelled DEMO project. None of its availability, dimensions, orientations or prices should be treated as genuine company data. No sample prices or customer testimonials are generated.
